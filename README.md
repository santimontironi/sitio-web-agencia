### FullWeb - Agencia de Desarrollo de Software

## Descripción del Proyecto

FullWeb es un sitio web corporativo desarrollado para una agencia de desarrollo de software, creado como proyecto final de carrera universitaria. La plataforma presenta los servicios, portafolio y capacidades de la agencia, ofreciendo una experiencia de usuario moderna y accesible.

---

## Objetivos

- Establecer presencia digital profesional para la agencia FullWeb
- Facilitar el contacto directo con potenciales clientes
- Mostrar servicios y capacidades técnicas de manera atractiva
- Proporcionar una experiencia de usuario optimizada en todos los dispositivos


---

## Características Principales

### Diseño Responsivo

- Adaptación fluida a diferentes tamaños de pantalla (móvil, tablet, desktop)
- Optimización de imágenes y recursos para carga rápida
- Navegación intuitiva en todos los dispositivos


### Interfaz de Usuario

- Diseño moderno y profesional
- Navegación clara y estructura de información jerárquica
- Elementos interactivos y animaciones sutiles


### Sistema de Temas

- **Modo Claro**: Interfaz luminosa para ambientes bien iluminados
- **Modo Oscuro**: Reducción de fatiga visual en ambientes con poca luz
- Persistencia de preferencia del usuario mediante `localStorage`


### Formulario de Contacto

- Integración con **FormSubmit** para gestión de mensajes
- Envío directo de consultas al correo electrónico corporativo
- Validación de campos en el cliente
- Confirmación de envío exitoso
